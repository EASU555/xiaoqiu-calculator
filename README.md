# 小秋计算器

一个简洁的 Windows 桌面计算与计数工具，提供：

- 总数：`A + B`
- 单独结果：`B ÷ 自定义除数`（默认除数为 `475`）
- 自定义乘加模式：`系数 × 乘数 + 加数 = 结果`（系数默认 `475`）
- 独立基础运算页：`固定值 + / - / × / ÷ 运算值 = 结果`（每次只选一个运算符）
- 独立快捷计数页：点击大号 `+1`、按 `Space` 或自定义快捷键加一，并可随时清零
- 双结果、乘加和基础运算分别保存最近 50 条正式计算记录

界面使用 CustomTkinter 6，采用浅灰白背景、白色工作面板、柔和阴影和橙色主操作，支持窗口缩放、高 DPI/显示缩放、圆角控件、悬停与焦点反馈，并优先使用“微软雅黑 UI”显示中文。

结果按 2 位小数进行四舍五入，并省略末尾无意义的 0。例如 `3.00` 会显示为 `3`，`1.50` 会显示为 `1.5`。
三个计算区域都会在输入完整有效时实时刷新结果，无需必须点击计算按钮。
实时预览不会写入历史；只有点击“计算结果”或按 Enter 完成的有效计算才会保存。

## 下载 Windows EXE

从 [GitHub Releases](https://github.com/EASU555/xiaoqiu-calculator/releases/latest) 下载 `ABCalculator.exe`。这是单文件程序，无需安装 Python。

## 直接运行源码

需要 Windows 上安装 Python 3，并确保 Python 自带 Tkinter。双击 `run_calculator.bat` 即可启动；脚本会在缺少 CustomTkinter 时自动安装。

也可以在命令行运行：

```powershell
python calculator.py
```

## 打包为 EXE

双击 `build_exe.bat`。脚本会检查并安装 PyInstaller，然后生成：

```text
dist\ABCalculator.exe
```

生成的 `ABCalculator.exe` 可直接在 Windows 上运行，不需要用户单独打开命令行。

如果希望手动执行打包命令：

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm --clean --onefile --windowed --exclude-module numpy --icon app_icon.ico --add-data "app_icon.ico;." --name ABCalculator calculator.py
```

## 输入规则

- 支持整数和小数，例如 `120`、`12.5`、`.5`。
- 支持负数，例如 `-10.25`。
- 右上角除数默认为 `475`，可直接修改为其他整数或小数；除数不能为 `0`。
- 输入为空或不是数字时，界面会在底部显示提示。
- 输入过程中遇到空值、`-`、`.` 等尚未完成的中间状态时，结果暂时显示为 `—`，不会反复弹出错误；点击计算或按 Enter 可进行明确校验。
- 单个输入最多 64 个字符；过长输入或无法安全显示的超大结果会被拒绝，而不会让程序崩溃。
- 回车键计算，Esc 键清空当前计算模式；在原双结果模式中，有效的自定义除数会继续保留。
- 计算器页顶部可切换“原双结果”和“乘加计算”模式；乘加系数默认 `475`，可在公式右上角自由修改。
- 乘加模式提供独立的“系数、乘数、加数”输入，支持整数、小数和负数，结果同样保留最多 2 位小数。
- 在乘加模式按 Esc 或点击“清空”会清空乘数和加数，并保留当前有效系数；非法或空系数会恢复为 `475`。
- “基础运算”是单独页面，固定值默认 `475` 且可修改；加、减、乘、除使用互斥选择器，一次只能启用一个。
- 基础运算顺序为“固定值 运算符 运算值”；进行除法时，运算值不能为 `0`。
- 在基础运算页按 Esc 或点击“清空”会清空运算值，并保留当前有效固定值。
- 双结果、乘加计算和基础运算均支持实时结果；切换基础运算符时也会立即重新计算。
- 三个计算模式的历史记录相互隔离，每种模式最多保留 50 条；历史自动保存到 `%APPDATA%\XiaoqiuCalculator\history.json`，重新启动后仍然存在。
- 每个计算页都有明确的“清空历史”按钮；清空前会显示确认窗口，而且只清空当前模式。
- `Space` 始终可以计数。点击计数器中的“快捷键”按钮，再按一个可用按键即可额外绑定快捷键；按 `Esc` 可取消绑定。
- 自定义计数快捷键会自动保存到 `%APPDATA%\XiaoqiuCalculator\settings.json`，下次启动继续使用。
- 字母、数字、标点、方向键、功能键和数字小键盘均支持绑定；程序同时记录 Windows 按键码，以兼容中文输入法和特殊键盘布局。
- 回车、Esc、Tab 和单独的 Ctrl/Alt/Shift 等操作键不会被占用；输入框获得焦点时，绑定键不会误触计数。
- 点击窗口顶部“快捷计数”按钮可进入独立计数页，点击“返回计算”或按 `Esc` 返回；计数快捷键只在计数页生效。

## 测试与稳定性

```powershell
python -m unittest discover -s tests -v
```

- 使用高精度 Decimal 上下文，覆盖超长数字、极小除数、除数为 0、非法格式和四舍五入边界。
- 依赖使用精确版本，GitHub Actions 也固定到具体提交，减少构建结果漂移与供应链风险。
- EXE 本身不联网、不读取无关用户文件，也不会写入注册表；只在 `%APPDATA%\XiaoqiuCalculator` 保存计数快捷键和计算历史。
- 每次推送都会在 Windows 环境运行测试并重新构建 EXE artifact。

## 界面决策

- Surface：轻量 Windows 工具，采用 Fluent 风格的低层级描边、圆角与语义状态反馈。
- 桌面 archetype：计算工作台 + 模式账本；主要对象是一次正式计算及其可追溯记录。
- 布局：固定标题与三页面导航 → 上方有界历史账本 → 下方输入、运算、紧凑结果和主操作 → 页面状态提示。
- 视觉锚点：历史行清晰呈现算式、结果和时间；结果与输入同属一个工作面板；计数页使用上方数字与下方大号 `+1`。
- 设计约束：使用“微软雅黑 UI”中文字体、浅灰背景、白色面板与单一焦橙色主操作；橙色仅用于主按钮、焦点和关键结果，成功与错误保留绿/红语义。
- 响应式：默认尺寸完整显示主流程；小窗口使用页面内部滚动，状态栏和键盘提示保持可见，控件不会横向溢出或被粗暴拉伸。
